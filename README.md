# Prabhupad Pradhan — Portfolio

Professional portfolio for a Frankfurt-based data scientist and AI engineer.

Live site: https://prabhupad26.github.io/

## November 2026 redesign

A responsive, static portfolio with selected projects, experience, published research, and skills. The redesign uses the existing profile portrait and keeps earlier Jekyll templates as historical reference, without depending on them at runtime.

### Files

- `index.html` — site content, structured metadata and accessible semantic HTML
- `assets/site.css` — responsive styling, typography and reduced-motion support
- `assets/site.js` — accessible mobile menu and current footer year
- `assets/favicon.svg` — favicon
- `.nojekyll` — serve directly via GitHub Pages without Jekyll

To preview locally, run `python3 -m http.server 8000` from the project root and visit http://localhost:8000.

Project descriptions reflect known research and engineering work. In-progress personal initiatives are labelled. No sensitive personal details or outdated résumé PDFs are exposed.
